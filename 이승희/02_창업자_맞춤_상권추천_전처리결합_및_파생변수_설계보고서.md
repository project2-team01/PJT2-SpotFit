# [SpotFit] STEP 2 & 3: 창업자 맞춤 상권 추천 전처리·결합 및 파생변수 설계 보고서

> **문서 버전**: v1.0 (최종 승인본)  
> **기준 시점**: 2025년 1분기 ~ 4분기 (2025Q1 ~ 2025Q4 최신 데이터셋 통합)  
> **분석 대상 공간/업종**: 서울시 1,650개 상권(골목·발달·전통·관광) × 62개 표준 생활밀접 업종 (총 21,333개 관측치)  
> **작성 목적**: 예비 창업자가 "어느 지역, 어떤 상권에서, 어떤 기회가 있는지" 객관적인 데이터에 기반하여 판단할 수 있도록 다차원 데이터를 결합하고, 추천 핵심 파생변수를 정의·검증함.

---

## Executive Summary (핵심 요약)

1. **문제 정의 (창업자의 딜레마)**:
   - 기존 상권 정보는 '총매출 1위(강남, 명동, 홍대 등)' 중심의 랭킹을 제공하여, **높은 임대료와 살인적인 경쟁(레드오션)**을 감당하기 어려운 소자본 예비 창업자에게 왜곡된 정보를 제공해 왔습니다.
   - SpotFit은 **"수요(매출 파이)는 크지만 경쟁(점포 수)은 상대적으로 적은 기회 상권(블루오션)"**을 발굴하고, 창업 안정성(폐업률, 생존 개월수)을 결합한 입체적 추천 엔진을 구축합니다.

2. **STEP 2 결합 결과**:
   - 상권 마스터(1,650개) + 행정동(425개) + 분기별 추정매출 + 점포 개폐업 + 상권변화지표 + 유동/직장/상주 배후인구 데이터를 `[상권_코드 × 서비스_업종_코드]` 기준의 **단일 통합 분석 마트(21,333행, 41개 컬럼)**로 완벽 결합하였습니다 (`상권_추천_통합마트_2025.parquet`).

3. **STEP 3 파생변수 체계**:
   - **기회 갭 지수(Opportunity Gap)**: 동일 업종 내 `수요 백분위수 - 경쟁 백분위수` (-100 ~ +100) 산출.
   - **수요-경쟁 2x2 사분면 유형**: 블루오션(14.3%), 격전지(36.0%), 틈새시장(35.6%), 레드오션(14.2%)으로 분류.
   - **SpotFit 종합 추천점수 (0~100점)**: `0.35 * 기회갭 + 0.25 * 점포당매출 + 0.20 * 상권안정성 + 0.20 * 배후유동` 가중치 모델 적용.

## 1. STEP 2: 데이터 전처리 및 다차원 결합 설계

### 1.1 결합 아키텍처 및 계층 구조 (Grain)

추천 시스템은 **2계층 하이브리드 탐색 구조**를 채택합니다:
- **1계층 (탐색 필터)**: 자치구(25개) 및 행정동(425개) 단위로 창업 희망 생활권역 선택.
- **2계층 (핵심 추천 단위)**: 실제 매장이 입점하는 **1,650개 골목상권·발달상권·전통시장 상권** 단위 추천.

```
[원천 1] 서울시 상권 영역 마스터 (1,650개 상권 좌표, 구, 동)
   │
   ├─ [원천 2] 2025년 상권 추정매출 (62개 업종, 매출액, 건수, 연령/시간대)
   ├─ [원천 3] 2025년 상권 점포 현황 (점포 수, 프랜차이즈 수, 개폐업 수)
   ├─ [원천 4] 상권변화지표 (운영/폐업 영업개월수, 상권변화 4대 유형)
   ├─ [원천 5] 배후 인구 및 시설 (유동인구, 직장인구, 상주인구, 집객시설)
   └─ [원천 6] 소상공인 53.5만 점포 (업종 매핑 및 1층 점포 접근성)
   │
   ▼
[통합 마트] data/processed/상권_추천_통합마트_2025.parquet (21,333행 × 41열)
```

## 2. STEP 3: 창업 추천 특화 파생변수(Feature) 설계 명세

### 2.1 4대 차원 파생변수 정의 및 산출식

| 차원 (Dimension) | 파생변수명 | 계산 수식 (Formula) | 비즈니스 의미 및 목적 |
| :--- | :--- | :--- | :--- |
| **1. 수익성** | `점포당_월평균매출_만원` | $\frac{\text{분기 매출금액}}{\text{전체 점포수} \times 3 \times 10,000}$ | 매장 1개당 평균적으로 기대할 수 있는 월 매출 규모 |
| | `건당_결제단가_원` | $\frac{\text{당월 매출금액}}{\text{당월 매출건수}}$ | 고객 1회 방문 시 결제하는 객단가 수준 (프리미엄 여부) |
| **2. 상대 백분위** | `수요_백분위수` ($D$) | $\text{rank}_{\text{pct}}(\text{당월 매출금액}) \times 100$ | 동일 62개 업종 내 해당 상권의 매출 파이 순위 (0~100) |
| | `경쟁_백분위수` ($C$) | $\text{rank}_{\text{pct}}(\text{전체 점포수}) \times 100$ | 동일 62개 업종 내 해당 상권의 점포 경쟁 밀집도 (0~100) |
| **3. 기회 척도** | `기회_갭_지수` ($Gap$) | $D - C$ | **수요 대비 경쟁 희소성** ($+$가 클수록 블루오션) |
| | `사분면_유형` | $D \ge 50$ 및 $C \ge 50$ 기준 4대 분류 | 상권의 입지 성격(블루오션/격전지/틈새/레드오션) 규정 |
| **4. 리스크·안정** | `폐업률` (%) | $\frac{\text{폐업 점포수}}{\text{전체 점포수}} \times 100$ | 단기 폐업 위험도 (낮을수록 안전) |
| | `안정성_점수` (0~100) | $\text{폐업률 감점}(50) + \text{운영개월 가점}(30) + \text{상권유형 가점}(20)$ | 상권에서 점포가 오래 살아남을 수 있는 지속 가능성 |
| **5. 고객 타깃** | `주요_소비_연령대` | $\text{argmax}(\text{연령대별 매출액})$ | 해당 매장의 주 타깃 고객층 (20대~60대이상) |
| | `2030_매출_비중` (%) | $\frac{\text{20대 매출} + \text{30대 매출}}{\text{전체 연령대 매출}} \times 100$ | 젊은 세대 및 트렌드 민감도 |
| | `피크_시간대` | $\text{argmax}(\text{6대 시간대별 매출액})$ | 주력 매출 발생 시간대 (점심/오후/저녁/야간 등) |

### 2.2 SpotFit 종합 추천 점수 (Composite Score) 모델

예비 창업자에게 여러 지표를 통합하여 직관적인 의사결정을 지원하기 위해 **0 ~ 100점 척도의 가중합 모델**을 수립하였습니다:

$$\text{SpotFit Score} = (0.35 \times \text{기회 갭 정규화}) + (0.25 \times \text{점포당 매출 백분위}) + (0.20 \times \text{안정성 점수}) + (0.20 \times \text{배후 유동 백분위})$$

- **기회 갭 정규화 (35%)**: $\frac{Gap + 100}{2}$ 로 변환하여 $0 \sim 100$점으로 리스케일링. (경쟁 대비 수요가 많을수록 높은 가점)
- **점포당 매출 (25%)**: 매장당 실제 거둘 수 있는 실질 수익성 반영.
- **안정성 점수 (20%)**: 낮은 폐업률과 긴 평균 생존 개월수 보장.
- **배후 유동인구 (20%)**: 기본 매장 집객을 보장하는 기초 유동인구 풀.

> 💡 **쉬운 해석**:
> 점수가 80점 이상인 상권은 "손님은 많고 경쟁 가게는 적으며, 기존 매장들의 폐업률이 낮고 유동인구가 탄탄한 **창업 최우선 추천 입지**"를 의미합니다.

## 3. 통계적 분포 검증 및 사분면 실증 분석

### 3.1 수요-경쟁 2x2 사분면 유형별 분포 현황

서울시 전체 21,333개 (상권 × 62개 업종) 관측치에 대한 사분면 분류 결과입니다:

| 사분면 유형 | 관측 건수 | 비중 (%) | 상권 특성 및 창업자 가이드 |
| :--- | :---: | :---: | :--- |
| **격전지 (스타형)** | 7,671건 | **36.0%** | • 수요도 높고 점포도 많은 대형 메가상권 (강남, 홍대, 종로 등)<br>• **가이드**: 막대한 자본과 차별화된 마케팅 역량을 갖춘 프랜차이즈/기업형 창업에 적합 |
| **틈새시장 (안정형)** | 7,595건 | **35.6%** | • 수요는 작지만 경쟁도 적은 로컬 골목상권 (주거지 배후)<br>• **가이드**: 소자본 1인 창업, 단골 고객 기반의 안정적 생계형 창업에 적합 |
| **블루오션 (기회형)** | 3,043건 | **14.3%** | • **매출 수요는 높은데 점포 수가 적은 절대적 기회 입지**<br>• **가이드**: 모든 예비 창업자가 가장 먼저 눈여겨봐야 할 1순위 추천 타깃 |
| **레드오션 (위험형)** | 3,024건 | **14.2%** | • 매출 파이는 작은데 점포만 난립한 과밀 과포화 상권<br>• **가이드**: 높은 폐업률과 출혈 경쟁 위험, **신규 진입 절대 회피 권고** |
| **합계** | **21,333건** | **100.0%** | 서울시 1,650개 상권 내 유효 영업 업종 전수 |

> 💡 **쉬운 해석**:
> 서울 시내에서 창업 기회가 열려 있는 '블루오션'은 전체의 약 14.3%(3,043건)에 불과합니다. SpotFit 추천 엔진은 바로 이 14.3%의 숨겨진 보석 같은 입지를 찾아내는 필터 역할을 수행합니다.
